## 1. Problem Statement

All previous milestones proved components of the thesis. N3.6 proves the
COMPLETE thesis:

> "A device without Internet can reach the real Internet through the
>  ShareNet mesh — using ordinary application traffic."

The client is an **ordinary HTTP client** (curl, browser). It has NO
knowledge of ShareNet. It just sends an HTTP request and gets an HTTP
response.

## 2. What Changed

### 2.1 ShareNet Proxy

New module: `reference/snp-node/src/node/north_star.rs`

- **ProxyRequest**: parses raw HTTP from ordinary clients (method, URL,
  headers, body). The URL is extracted from the query string
  (`/?url=https://example.com`).
- **ProxyResponse**: encodes an HTTP response with an `X-ShareNet: true`
  header proving the mesh was used.
- **ShareNetProxy**: listens on `127.0.0.1:port`, accepts HTTP connections,
  parses requests, tunnels them through the ShareNet mesh, returns responses.
- **NorthStarDemo**: orchestrates the demo — starts the proxy, fetches
  through it, verifies the `X-ShareNet` header.

### 2.2 What the client sees

The client sees a normal HTTP response:
```
HTTP/1.1 200 OK
Content-Type: text/plain
X-ShareNet: true
Content-Length: 42

ShareNet north-star demo! ...
```

The `X-ShareNet: true` header is the ONLY indicator that the response
went through the mesh. The client can ignore it — it's just HTTP.

### 2.3 What the client does NOT know

- That ShareNet exists
- That the request went through a relay
- That a gateway fetched from the Internet
- That the response was tunneled through CBOR over TCP

## 3. The Full Pipeline (N2.5 → N3.6)

```text
Ordinary HTTP Client (curl/browser)
    ↓ HTTP GET /?url=https://example.com
ShareNet Local Proxy (N3.6 — this module)
    ↓ TransitRequest (CBOR)
Relay (N3.3 — multi-process TCP)
    ↓ forward
Gateway (N2.7 — GatewayServiceManager)
    ↓ Policy enforcement + quota check
    ↓ PinnedConnector (N2.8 — real HTTP fetch)
Real Internet (https://example.com)
    ↓ HTTP response
Gateway → Relay → Proxy
    ↓ HTTP response + X-ShareNet: true
Ordinary HTTP Client
```
