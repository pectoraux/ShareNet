# N2.3 V1 Protocol Conformance Checklist

**Frozen at:** commit `0efaaac`
**Profile:** `PacketProfile::V1`
**Status:** FROZEN — DO NOT MODIFY

This document defines the immutable conformance invariants for the N2.3 v1
circuit packet protocol. Any change to any item below requires a protocol
version bump, ADR update, and explicit architectural approval.

## Required invariants

### 1. Packet layout

```text
CircuitPacketV1 {
    circuit_id: [u8; 32],
    seq: u32,
    ttl: u8,
    payload: Vec<u8>,
    final_dst: [u8; 32],
}
```

- 5 fields. No direction. No flow_id. No version field.
- V1 is a forward-only protocol.
- **V1 dispatch is circuit-profile selected.** V1 does not have wire
  self-description (no `"v"` field). The V1 profile is determined at circuit
  establishment time (`accept_relay_handshake` sets `RelayForwardingState.profile`).
  The absence of a version field is part of the immutable V1 wire format.
  **Do NOT use CBOR map size as a version identifier** — the 5-entry count
  is a structural observation, not a protocol guarantee. Future protocol
  versions may add optional fields that change the map size without changing
  the version. Only the explicit `"v"` field (V2+) and the circuit-level
  profile binding (V1) are authoritative version selectors.

### 2. CBOR wire format

- 5-entry CBOR map.
- Keys (canonical sort by encoded bytes): `circuitId`, `finalDst`, `payload`, `seq`, `ttl`.
- Golden wire vector: `public/conformance/vectors/11-circuit-packet-v1.json`.
- The `json_golden_vector_is_authoritative` test reads the JSON file and asserts exact bytes. Any change breaks CI.

### 3. AAD construction

```text
AAD = circuit_id || seq(BE) || ttl || final_dst
```

- NO domain-separation prefix.
- NO direction byte.
- NO flow_id.
- The AAD is raw field concatenation.

### 4. Nonce construction

```text
nonce = circuit_id[0..8] || seq(BE)
```

- 8-byte fid from circuit_id's first 8 bytes.
- NO direction XOR.
- 4-byte seq in big-endian.

### 5. TTL semantics

- Starts at `PACKET_TTL_MAX` (= `ROUTE_MAX_HOPS` = 16).
- Decremented by 1 per relay.
- `ttl == 0` → `TtlExhausted` (drop, do not forward).
- TTL is authenticated per-hop in the AAD.

### 6. Replay semantics

- `check()` is read-only (before AEAD).
- `commit()` runs only after successful AEAD.
- O(WINDOW) update (WINDOW = 1024).
- `seq == 0` → `SequenceZero` (invalid).
- `seq == u32::MAX` → exhaustion, no wrap.
- `initialized` flag (not `max_seen == 0` sentinel).

### 7. Forwarding behavior

- Relay peels one AEAD layer (decrypt) with its `forwarding_key`.
- Non-terminal relay forwards the inner bytes as the next AEAD layer.
- Terminal relay (gateway, `successor = None`) delivers the inner bytes as plaintext.
- Predecessor check: packet came from registered predecessor.
- Successor comes from installed state (not from packet).
- Circuit expiration: `now >= expires_at` → `CircuitExpired` (before AEAD).
- Profile mismatch: `state.profile != V1` → `ProfileMismatch` (before AEAD).

### 8. Error handling

- Fail-closed: no `unwrap_or_default`, no `expect()` in production paths.
- AEAD failure → `PacketUnauthentic`, no partial state mutation.
- Replay check failure → `PacketReplayOrStale`, no replay state mutation.
- Unknown circuit → `UnknownCircuit`.
- Teardown → `remove_circuit()`, subsequent packets rejected.

### 9. Sequence allocator ownership

- `CircuitSeqState` is `pub(crate)`, `!Clone`.
- `ActiveCircuit` owns the allocator. `ActiveCircuit` is `!Clone`.
- `CircuitSender::new` is `pub(crate)`.
- No independent production allocator constructible from `circuit_id + hops`.
- `wrap_packet` is `pub(crate)`. Test-only `wrap_packet_v1_for_testing` is `#[cfg(feature = "test-utils")]`.

### 10. Golden wire vector

- File: `public/conformance/vectors/11-circuit-packet-v1.json`
- The test `json_golden_vector_is_authoritative` loads this file at runtime, constructs the packet from the JSON input, encodes it, and asserts the exact `expectedWire` hex bytes.
- Any change to v1 encode/AAD/nonce/CBOR that produces different bytes breaks this test.
- The test is the immutable wire contract.
